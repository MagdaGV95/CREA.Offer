# Checklist semanal de métricas (Jun Yuh: STOP → STAY → SHARE)

En Instagram: reel → "Ver estadísticas". Revisa cada domingo.

| Reel | Skip rate (vs tu típico) | Retención (tiempo prom. ÷ duración) | Envíos | Qué cambio |
|---|---|---|---|---|
| | | | | |

1. **Skip rate peor que tu típico** → cambia el hook (primeros 3 s): texto + visual + dolor específico.
2. **Retención baja (< 30–40%)** → acorta, re-hook a la mitad, mejora el ritmo.
3. **Pocos envíos** → nombra un dolor más específico y da una solución accionable; usa CTA "envíaselo a…".
No te guíes primero por likes ni seguidores.
